# 10 · 待验证事项与明确保留的未知

这份清单防止把**架构愿景当成已知平台能力**，也不代表已经开始开发计划。

## 第三方接入能力

- Muse 云端电脑的运行环境、用户权限、持久性、Codex CLI 兼容与是否允许隔离执行。
- Muse 是否提供官方、稳定、可审计的外部触发、Webhook、任务状态接口、后台持续运行能力。
- Codex Plus/Cloud/CLI 在对应账号及使用方式下的真实调用、认证、任务状态、自动接单和使用限制。
- Google AI Pro 所关联工具的实际服务入口、官方接口、认证模式和使用限制。
- 外部 Agent 是否支持 MCP Client/Server、A2A Endpoint、轮询任务或等价标准 Runner。
- 多订阅账号不能作为 API 配额池；可观测性与配额数据来源需逐一确认。

## 技术与运行边界

- 控制平面在目标负载下的 PG + Web + 协议服务资源曲线；连接数、事件吞吐和存储增长。
- 备份对象、频率、保留期、恢复时间目标、恢复演练及故障时只读能力。
- 私人 Web 的访问方法，以及外部 Agent 无法进入私人网络时的最小 HTTPS 接入面。
- 具体 Secrets 存储与密钥轮换/撤销设计；外部已接收数据的清理能力。
- 是否、何时需要 pgvector / WebSocket / 消息中间件；不要预先假定。
- 高风险外部副作用操作的结果核验与去重方案。
- 评价数据集的可靠性、平台相关偏差与安全回归门槛。

## 当前仍不启动的工作（开发已开始）

- 完整产品开发已经启动；**暂不进行生产部署、公网暴露或真实第三方账户接入**。
- 不提前开发为未验证平台量身打造的专用适配器。
- 不根据假设配额、假设 Agent 运行状态或假设付费接口作工程承诺。

## 项目维护建议

- 本仓库首先作为产品与架构**唯一设计基准**；日后发生重大修改请补充 ADR，并同步相关文档。
- 真实验证结果需要标记日期、环境、来源，不覆盖未验证的历史假设。
- 用户后续若决定进入实现阶段，再单独讨论实施范围；本文档目前作为研发过程的约束；完整产品开发已有用户授权，生产部署及外部平台接入仍需另行验证和审批。
