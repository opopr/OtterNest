# 04 · 标准协议与互操作

协议/能力名单共 **8 项**，但**并非八种都属于网络通信协议**。

| 名称 | 规划职责 | 边界 |
|---|---|---|
| **MCP** | 给 Agent 提供任务、记忆、成果、授权工具 | 工具可访问 ≠ Agent 能被远程唤醒 |
| **A2A** | Agent 能力描述、任务委托与状态交互 | 仅用于真正提供标准端点的执行者 |
| **REST / OpenAPI** | 中央通用业务 API、Web 与通用执行器访问 | 不为某个平台重复实现业务规则 |
| **Webhook** | 已授权事件推送、外部回调 | 要求真实回调端点、鉴权、签名、重试 |
| **Agent Skills** | SKILL.md 等工作指导、模板、工具说明 | 属于可复用技能规范，不是网络传输协议 |
| **SSE / WebSocket** | Web 端状态、事件与活动流 | SSE 优先轻量化，断线重连需追补持久事件 |
| **AG-UI** | 增强 Agent 与用户界面事件交互 | 在基础 Web 可用后逐步增强 |
| **A2UI** | 结构化、受限的 Agent 生成界面 | 组件白名单、权限/内容安全审查 |

## 接入模型

- 平台账号注册不等于成功接入；还要登记实际 runner/endpoint/CLI/轮询能力。
- 尽量使用**标准协议和通用执行器**；如果平台不支持直接受控调用，就只标记能力限制，不假定它可以作为后台 Worker。
- 外部云端执行器如果无法持续运行，则可能需要官方支持的触发/计划任务能力或用户主动启动。
- 不直接暴露 PostgreSQL、私人管理入口、登录 Cookie 或共享主账号凭据给外部 Agent。

## 接口安全与语义

- 每个执行者拥有独立认证身份、限定项目/任务/操作范围的短期授权。
- 所有读取、写入、委托在**服务端统一校验**；输入 Schema 校验、速率限制和审计。
- Webhook 校验签名、时间戳、防重放标识，失败有指数退避和上限。
- A2A Agent Card、MCP 发现结果和 Skill 来源仅用于**候选能力声明**；需进行身份/信任及能力验证。
- 接口返回标准状态：已接受请求、已排队、被实际执行器接收、已运行、成功/失败或未知。
- OpenAPI、MCP/A2A 接入层调用统一业务命令；协议适配**不得生成绕过授权的私有后门**。

## 需要事实验证

Muse 的远程触发、云电脑稳定性以及运行 Codex CLI 的权限；Codex 云端/CLI 的可控接口；Google AI Pro 对应实际工具的调用机制、配额与条款。不要把订阅等同官方 API。
