认证与上线部署边界

  • 管理员会话（当前）：通过环境变量 OTTERNEST_OWNER_TOKEN 恒定时间校验，关闭页签即失效。
  • Agent 独立凭据：注册时生成一次性 on_agent_* 令牌，数据库只保存 SHA-256 哈希，并按角色与 lease_epoch 隔离。
  • 生产上线前提：当前版本尚未内置企业 SSO / OAuth 与多管理员 RBAC；生产部署必须置于 HTTPS 与企业统一身份认证网关之后。
